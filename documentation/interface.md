# Interface Direction

## Expanded Panel

The expanded experience has two layers.

1. The outer window is a restrained translucent backdrop. It confirms that Skill Pet is active while keeping the desktop visible.
2. The centered content deck is the reading surface. It keeps titles, search, and skill groups aligned on one stable column, independent of which corner contains the SP ball.

The SP ball is a persistent window control, not content. When the panel opens from the top, the deck reserves vertical space above itself; when it opens from the bottom, it reserves vertical space below. No horizontal content shift occurs.

## Information Hierarchy

1. Header: skill count and manual refresh.
2. Search: one clear entry point for names, uses, and plugin sources.
3. Group row: group name, a one-line skill-name preview, a two-line function summary, and count.
4. Expanded group: concise individual skill rows directly below the selected group.

This keeps the default state scannable while preserving detailed names and functions on demand.

## Visual Principles

- Use translucency to separate the tool from the desktop, not to obscure the content.
- Use one restrained blue accent for active groups, counts, refresh, and SP.
- Keep dense product information in ruled rows rather than oversized cards.
- Keep the centered deck at a stable maximum width so the panel feels composed on every monitor position.
